// about

A club built around the CTF, not around a syllabus

Mahendra CTF Club is where students from any branch — not just CSE — come to learn how systems actually break. We run weekly practice rounds, walk through past challenges line by line, and send teams to inter-college and online CTFs through the year.

No prior hacking experience required. You'll start with guided challenges in your first few weeks, and be picking locks — figuratively — soon after.

// tracks

Six categories, one scoreboard

Every CTF splits into a handful of domains. We run dedicated practice for each so no one's stuck guessing on competition day.

</> web

Web Exploitation

SQLi, auth bypass, SSRF, template injection — breaking apps the way they're built to be used, just wrong.

0x00 pwn

Binary Exploitation

Buffer overflows, stack smashing, ROP chains. Reading assembly like it owes you money.

Σ crypto

Cryptography

Breaking weak ciphers, RSA math attacks, and spotting crypto used where it shouldn't be trusted.

◧ forensics

Digital Forensics

Packet captures, disk images, memory dumps — recovering the story a file is trying to hide.

↻ reverse

Reverse Engineering

Disassembling binaries to work out what they actually do, with no source code in sight.

// how a semester runs

The path from first meet to first solve

WEEK 1–2

Fundamentals

Linux basics, command line comfort, and how a CTF flag actually gets planted and found.

WEEK 3–6

Track rotation

Guided challenges across all six domains, so you find the one that clicks before specializing.

WEEK 7–10

Team formation

Small teams form around shared interests and start tackling harder, multi-step challenges together.

WEEK 11+

Live competition

Teams enter online and on-campus CTFs, with the club providing a room, snacks, and a Discord war-room.
